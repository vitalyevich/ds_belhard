# Датасет AB_NYC_2019 (Airbnb NYC) — сводная информация и показатели по объектам недвижимости в Нью-Йорке. 

Сервис Airbnb – самый популярный онлайн-инструмент среди туристов для кратковременной аренды частного жилья.

В этом проекте анализируются данные Airbnb по Нью-Йорку за 2019 год, чтобы изучить различия в ценах и доступности среди разных групп районов Нью-Йорка, выявить самых загруженных хозяев в Нью-Йорке и построить предварительную модель линейной регрессии для прогнозирования цены листинга для каждого листинга.


Включает следующие характеристики (столбцы):
- id — идентификатор листинга
- name — название листинга
- host_id, host_name — данные хозяина
- neighbourhood_group, neighbourhood — район города
- latitude, longitude — географические координаты
- room_type — тип жилья (Entire home / Apartment, Private room, Shared room)
- price — цена за ночь
- minimum_nights — минимальное количество ночей аренды
- number_of_reviews, reviews_per_month — отзывы
- calculated_host_listings_count — сколько объектов у хозяина
- availability_365 — доступность в течение года
- и др.
